# VRP-GO - PHAN VIEC CUA HIEU

Thu muc chinh: `vrp-go-hieu/`

## 1. Lich thue theo tuan (Hieu)
- `vrp-go-hieu/khach-hang/calendar.html`
- `vrp-go-hieu/khach-hang/css/calendar.css`

Chuc nang:
- Bam "Thue xe" o the xe nao thi lich chi hien dung xe do.
- Cot ngay tu Thu 2 den Chu nhat, ngay thang tu dong theo tuan hien tai.
- Nut Tuan truoc / Tuan sau / Hom nay hoat dong.

## 2. Ho so ca nhan (Hieu)

- `vrp-go-hieu/khach-hang/css/account.css`

Chuc nang:

- Upload anh giay phep lai xe (xem truoc anh).
- Don thue, xe yeu thich, danh gia.
